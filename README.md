# «Нұрзат» — kindergarten document portal

Online archive of official documents for **«Нұрзат»** kindergarten: 130+ files grouped into 13 categories — administrative documents, monitoring, individual development, psychologist, nurse, teacher certificates, cyclograms, timesheets and more. Every document opens right in the browser.

🔗 **Live:** https://nurzat.vercel.app · main website: https://www.nurzat-sadikedu.kz

## Tech

React 19 · Vite · JavaScript · deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```
